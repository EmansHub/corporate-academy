# Corporate Academy

A weekly course management and display application developed in two versions.

## Versions

### Version 1 — Firebase / Vanilla JavaScript

The first version of the project uses:

- HTML
- CSS
- JavaScript
- Firebase Firestore
- Firebase Hosting

This is the version currently connected to Firebase and deployed as the working application.

### Version 2 — React / Vite

The second version is the project generated from Figma Make and uses:

- React
- Vite
- JavaScript/TypeScript

This version is kept separately from the Firebase/vanilla JavaScript implementation for comparison and development.

## Project Purpose

Corporate Academy is designed to display and manage weekly courses, including information such as:

- Course name
- Department
- Instructor
- Room
- Start and end dates
